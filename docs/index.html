Cross-Platform Support

🌐

JavaScript (Web)

Open in any browser - no dependencies required. Pure HTML5 Canvas with 60fps animation.

Open *.html in browser
🐍

Python (LVGL/pygame)

For embedded Linux (Raspberry Pi) with LVGL, or desktop with pygame.

pip install -r requirements.txt
python lvgl_demo.py
🦀

Rust (embedded-graphics)

For bare-metal ARM systems like STM32F469. No OS required, no_std compatible.

cargo run --features simulator
cargo build --release
