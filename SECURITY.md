# Security Policy

## Status

This repository is an archived experiment (see the status note at the end
of the README): an agentic-AI development scaffold kept as a workflow
artifact, with no completed product and no supported releases.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting on this repository
(**Security** tab → **Report a vulnerability**) rather than a public
issue.

## Scope notes

- The JavaScript demos run fully client-side in the browser; they make no
  network calls.
- The Python (pygame/LVGL) and Rust (embedded-graphics) implementations
  are local demos with no network listeners.
- The GitHub Actions workflow only regenerates screenshots and commits
  them back to the repository.
